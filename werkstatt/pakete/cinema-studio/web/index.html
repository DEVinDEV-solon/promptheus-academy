Cinema Studio öffnest du über die Werkstatt

Eine Anmeldung brauchst du hier nicht. Der Weg hinein führt immer über die Werkstatt:

  1. Die Werkstatt aus der Academy öffnen: Einstellungen → Werkstatt → „Werkstatt öffnen“.
  2. In der Werkstatt links unten auf „Cinema-Studio“ klicken.
  3. Cinema Studio öffnet sich in einem neuen Tab. Diesen Tab hier kannst du schliessen.
