# Perchance AI Character Generator

> Kostenloses, browserbasiertes KI-Tool zum Erstellen fiktionaler Charaktere (OC, Schurken, RPG/D&D/Fantasy) — ohne Login, ohne Begrenzung, Open Source.

## Was es ist
- Perchance ist eine Plattform mit unendlich vielen nutzergemachten AI-Generatoren.
- Der **AI Character Generator** erstellt nach Text-Eingabe vollständige Charaktere: Aussehen + Persönlichkeit + Hintergrund.
- Basierend auf modularen Prompt-Systemen + **Llama-Inference** (Expander/Text);
- **Bild-Generierung** über **Stable Diffusion** (text-to-image).
- Zielgruppe: Autoren, Kreative, Rollenspieler (D&D/RPG), Gamedesigner.
