# Was ein Agent ist — für Lehrkraft

## Sprechertext

Stellen Sie sich vor, Sie haben ein Programm, das jede Nacht eine Nachricht liest, entscheidet, ob sie wichtig ist, und dann eine Antwort schreibt. Das ist ein Agent. Er nimmt wahr, er entscheidet, er handelt – und dann beginnt die Schleife von vorn. Der Unterschied zu einer festen Regel ist entscheidend: Eine Regel tut immer dasselbe, ein Agent tut meistens dasselbe. Und genau da hängt die Klasse. Viele denken, ein Agent sei nur eine Wenn-Dann-Kette mit einem Modell dran. Aber das Modell macht die Sache unberechenbar. Bei tausend Läufen passieren zehn Fehler – und die Frage ist, ob das tragbar ist. Das sollten Sie nicht theoretisch erklären, sondern vorführen. Lassen Sie die Klasse einen Agenten bauen, der eine einfache Entscheidung trifft, und dann ändern Sie die Eingabe leicht. Die Klasse sieht sofort: Manchmal reagiert er anders, obwohl die Regel gleich bleibt. Das ist der Moment, wo es klickt. Rechnen Sie für diese Lektion etwa zwanzig Minuten ein, wenn Sie die Diskussion über die Fehlerquote mitnehmen. Mehr braucht es nicht, um den Kern zu treffen.
