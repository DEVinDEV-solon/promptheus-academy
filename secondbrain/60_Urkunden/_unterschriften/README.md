# Unterschriften — Prometheus · Athena · Hermes

Jede Abschluss-Urkunde trägt unten in einer Linie drei Unterschriften:

| Datei | Unterzeichner | Rolle in der Academy |
|---|---|---|
| `prometheus.png` | Prometheus | Haupttutor |
| `athena.png` | Athena | Prüferin |
| `hermes.png` | Hermes | Bibliothekar |

Hephaistos unterzeichnet **nicht** — er ist der Werkzeugmacher der Werkstatt und
tritt erst im 7. Kurs auf, nach der Urkunde.

**Stand 30.09.2026: die drei PNG fehlen noch.** Bis sie hier liegen, zeigt die
Urkunde an jeder Stelle eine Linie mit Name und Rolle darunter.

## Wie die Datei aussehen muss

- **PNG**, höchstens 2 MB.
- **Eng zugeschnitten** auf den Schriftzug — etwa **4 : 1 bis 5 : 1** (z. B. 1000 × 230 px).
  Der Bildgenerator liefert 9:16; der Schriftzug liegt dann in einem schmalen
  Streifen in der Mitte und muss ausgeschnitten werden.
- **Weisser oder durchsichtiger Grund.** Die Urkunde legt das Bild mit
  „multiply" auf das Papier — Weiss verschwindet dabei auf jedem Pergament.
- **Dunkle Tinte**, eine Farbe. Kein Schatten, kein Papier, keine Linie darunter
  (die zieht die Urkunde selbst).

Die Prompts: `prometheus-bildprompt.md`, `athena-bildprompt.md`, `hermes-bildprompt.md`.
