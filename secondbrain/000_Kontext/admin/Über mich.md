# Über mich

## Wer bin ich

Solon, Full-Stack Softwareentwickler und Automations-Spezialist mit Fokus auf produktionsreife Lösungen. Betreibt DEVinDEV Development (devndev.de) und das KI-Agenten-Projekt Agent0 (agent0.de). Arbeitet projektbasiert mit Mandanten aus verschiedenen Branchen — ausschließlich über Empfehlungen, kein aktives Marketing.

## Technischer Stack

- **Backend:** PHP 8.2 / Laravel
- **Frontend:** JavaScript, CSS
- **Datenbanken:** PostgreSQL, MySQL, SQLite
- **Infrastruktur:** Linux, Docker, Nginx
- **Automationen:** Node-RED, n8n
- **Messaging:** Telegram-Bots, WhatsApp-Integration
- **KI/Agenten:** Claude, Agent0-Multiagentensystem, MCP, VectorDB, Obsidian Memory

## Arbeitsumgebung

- Entwicklung: Windows (C:\-Pfade)
- Deployment: Linux-Server
- Zeitzone: Europa/Berlin

## Arbeitsstil

Strukturiert und organisiert — gleichzeitig kreativ-chaotisch mit vielen spontanen Ideen. Schritt-für-Schritt-Vorgehen: erst Plan/Checkliste, dann Implementierung, dann Test, dann Hardening. Wert auf klare Module, nachvollziehbare Entscheidungen und Wiederverwendbarkeit.

## Fachgebiete

- Full-Stack Webentwicklung (Webseiten, SEO, Apps)
- Automationen und Workflow-Systeme (n8n, Node-RED)
- KI-Agenten und Multiagentensysteme (Agent0)
- Security, DSGVO, AI Act
- Prompt Engineering und Promptbibliotheken
- Voice Assistants und Audio-Projekte

## Werte und Positionierung

Direkt, lösungsorientiert, effizient. Kein Interesse an Theorie ohne Praxis. Fokus auf produktionsreife, skalierbare und wartbare Lösungen. Mandanten bekommen was sie brauchen — egal aus welcher Branche.
