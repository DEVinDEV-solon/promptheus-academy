# Pull Request

> Ein Pull Request bündelt Änderungen und bittet darum, sie in den Hauptstand zu übernehmen.

Andere können die Änderungen lesen, kommentieren und automatisch testen lassen. Erst nach Prüfung wird übernommen.

**Für Agenten ist das die natürliche Grenze**: Sie dürfen Vorschläge machen, das Übernehmen entscheidet ein Mensch.
