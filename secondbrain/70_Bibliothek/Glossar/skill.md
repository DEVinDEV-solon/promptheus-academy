# Skill (Agent)

> Ein Skill ist ein Ordner mit einer Anleitung und Hilfsmitteln, die ein Agent liest, wenn eine passende Aufgabe kommt.

Statt alles Wissen ständig im Kontext zu haben, kennt der Agent nur die Kurzbeschreibungen und lädt den vollständigen Skill erst bei Bedarf. Das spart Platz und hält ihn fokussiert.

Skills sind prozedurales Gedächtnis zum Mitnehmen: einmal geschrieben, von vielen Agenten nutzbar. **Ein fremder Skill kann Anweisungen und Code enthalten** — er verdient dieselbe Prüfung wie ein Programm.
