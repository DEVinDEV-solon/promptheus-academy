# Flüssigkühlung

> Flüssigkühlung führt Wärme über Wasser oder spezielle Kühlmittel ab, die direkt an den Chips vorbeifliessen.

Moderne KI-Chips erzeugen so viel Wärme auf so kleiner Fläche, dass Luft nicht mehr reicht. Flüssigkeit nimmt Wärme viel besser auf.

Ein Nebeneffekt: Die abgeführte Wärme ist so warm, dass man sie weiterverwenden kann.
