# Fehlerbehandlung (Agent)

> Fehlerbehandlung legt fest, wie ein Agent oder Programm auf Störungen reagiert: noch einmal versuchen, anders versuchen, aufgeben oder einen Menschen fragen.

Bei Agenten kommt hinzu: Die Fehlermeldung wird dem Modell gezeigt, damit es daraus lernt. Eine verständliche Meldung hilft dem Modell genauso wie einem Menschen.

**Eine Fehlermeldung ohne Weg ist eine Sackgasse** — auch für eine Maschine.
