# Agent

> Ein Agent ist ein Modell in einer Schleife: wahrnehmen, entscheiden, handeln — und dann noch einmal, mit dem Ergebnis der eigenen Handlung.

Der Unterschied zum Chat ist die Handlung. Ein Chat gibt Text zurück. Ein Agent darf suchen, rechnen, Dateien schreiben, eine Nachricht schicken — und sieht danach, was dabei herauskam.

Das macht ihn nützlich und heikel zugleich: Ein falscher Satz ist ärgerlich, eine falsche Handlung ist ein Schaden. Deshalb gilt für Agenten dieselbe Regel wie für Praktikanten — was rückgängig zu machen ist, darf man allein tun lassen.

Die vier Tutoren dieser Academy sind Agenten in diesem Sinn.
