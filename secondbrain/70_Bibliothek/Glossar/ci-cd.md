# CI/CD

> CI/CD lässt bei jeder Änderung Tests, Prüfungen und Bauschritte automatisch laufen.

Fällt etwas durch, wird die Änderung angehalten. So erreicht Kaputtes die Nutzer seltener.

Für Agenten ist das eine wichtige Absicherung: Was sie ändern, muss dieselben Prüfungen bestehen wie menschlicher Code.

CI steht für das ständige Zusammenführen und Prüfen, CD für das automatische Ausliefern. Wie streng die Prüfung ist, legt das Team fest. Ein grüner Haken zeigt nur, dass die vorhandenen Tests bestanden wurden — nicht, dass alles richtig ist.
