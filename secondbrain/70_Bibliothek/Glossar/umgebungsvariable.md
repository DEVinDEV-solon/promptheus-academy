# Umgebungsvariable

> Eine Umgebungsvariable ist ein benannter Wert, den das Betriebssystem einem Programm beim Start übergibt.

Schlüssel und Passwörter werden oft so übergeben, damit sie nicht im Code stehen.

**Sicher sind sie damit nicht automatisch**: Wer das Programm kontrolliert, kann sie auslesen — auch ein Agent mit Shell-Zugriff.
