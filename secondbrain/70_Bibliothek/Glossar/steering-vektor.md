# Steering-Vektor

> Ein Steering-Vektor ist eine Richtung im Inneren des Modells, die für eine Eigenschaft steht — etwa Höflichkeit. Addiert man sie, wird das Modell höflicher.

Das funktioniert ohne neues Training und ohne Prompt. Forschende nutzen es, um zu prüfen, ob sie eine Eigenschaft wirklich gefunden haben.

Für den Alltag ist es noch eine Laborteknik, zeigt aber, wie greifbar manche Eigenschaften im Modell liegen.
