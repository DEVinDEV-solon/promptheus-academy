# Hilberts zehntes Problem

> Hilbert fragte 1900, ob es ein Verfahren gibt, das für jede Gleichung mit ganzen Zahlen entscheidet, ob sie eine Lösung hat. 1970 fiel die Antwort: Es gibt keines.

Juri Matijasewitsch löste das Problem in Leningrad — negativ. Das Ergebnis ist äquivalent zum Halteproblem: Die Frage ist nicht schwer, sondern unentscheidbar.

Damit war zum ersten Mal ein mathematisches Problem gefunden, von dem bewiesen war: Der digitale Rechner kann es prinzipiell nicht.
