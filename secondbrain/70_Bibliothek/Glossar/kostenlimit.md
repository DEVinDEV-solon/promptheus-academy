# Kostenlimit

> Ein Kostenlimit hält den Agenten an, wenn eine festgelegte Summe an Token oder Geld erreicht ist.

Agenten können sehr viele Token verbrauchen, besonders mit Subagenten und langem Nachdenken. Ohne Grenze kann eine harmlose Aufgabe eine überraschend hohe Rechnung erzeugen.

**Ein Limit pro Aufgabe ist Pflicht**, ein Limit pro Monat ist klug.
