# Ratenlimit (Rate Limit)

> Ein Ratenlimit begrenzt, wie viel ein Konto in einer Zeitspanne von einem Dienst abrufen darf.

Anbieter schützen damit ihre Server und verteilen die Leistung fair. Wer das Limit überschreitet, bekommt eine Fehlermeldung und muss warten.

**Gute Programme rechnen damit**: Sie warten nach einer Ablehnung kurz, versuchen es erneut und verlängern die Pause, wenn es wieder scheitert.
