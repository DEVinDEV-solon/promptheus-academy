# A2A (Agent-to-Agent-Protokoll)

> A2A legt fest, wie ein Agent einen anderen findet, ihm eine Aufgabe übergibt und das Ergebnis zurückbekommt — egal, wer die beiden gebaut hat.

MCP verbindet einen Agenten mit Werkzeugen und Daten. A2A verbindet Agenten untereinander. Beide ergänzen sich: Der eine Stecker führt zu den Werkzeugen, der andere zu den Kollegen.

Die Norm wird von einer herstellerübergreifenden Stiftung gepflegt. **Ob sie sich durchsetzt, entscheidet die Praxis**, nicht die Ankündigung.
