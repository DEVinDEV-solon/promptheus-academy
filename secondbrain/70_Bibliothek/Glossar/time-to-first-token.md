# Time to First Token

> Time to First Token misst die Zeit vom Abschicken bis zum ersten sichtbaren Token.

Sie hängt vor allem an der Länge des Prompts, an der Auslastung des Anbieters und daran, ob das Modell erst nachdenkt. Denkmodelle haben oft eine lange Zeit bis zum ersten Antwort-Token.

Für das Gefühl von Tempo ist sie wichtiger als das Gesamttempo: Eine Antwort, die sofort zu laufen beginnt, wirkt flott.
