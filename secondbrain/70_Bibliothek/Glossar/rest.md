# REST

> REST organisiert eine Schnittstelle um Adressen und wenige Grundbefehle: lesen, anlegen, ändern, löschen.

Fast alle Webdienste bieten so eine Schnittstelle an. Sprachmodelle werden ebenfalls meist über REST angesprochen.

Wer das Prinzip kennt, kann sich in fremden Schnittstellen zügig zurechtfinden.

Eine REST-Anfrage besteht aus einer Adresse, einem Befehl und meist einem JSON-Inhalt. Die Antwort enthält einen Statuscode, an dem man sofort sieht, ob alles geklappt hat oder ob etwa die Anmeldung fehlt. Agenten können solche Schnittstellen nach einer kurzen Beschreibung selbst bedienen.
