# Selbstüberwachtes Lernen

> Beim selbstüberwachten Lernen macht man aus Rohdaten eine Aufgabe, deren Lösung schon drinsteht: Man verdeckt ein Stück und lässt es erraten.

So lernen Sprachmodelle. Jeder Satz im Netz ist eine Übungsaufgabe: Was kommt als Nächstes? Die Antwort steht im Text, niemand muss sie beschriften.

**Das ist der Grund, warum Sprachmodelle so gross werden konnten.** Beschriftete Daten sind knapp, Text gibt es fast unbegrenzt. Erst diese Idee machte das ganze Internet zum Lehrbuch.
