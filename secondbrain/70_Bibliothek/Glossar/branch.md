# Branch (Zweig)

> Ein Branch ist eine Abzweigung vom Hauptstand. Darauf entsteht eine Änderung, bis sie fertig ist und zurückgeführt wird.

So können mehrere Menschen und Agenten gleichzeitig an verschiedenen Dingen arbeiten. Agenten bekommen oft je einen eigenen Branch.

Geht ein Versuch schief, wirft man den Branch weg, und der Hauptstand ist unberührt. Diese Freiheit zum Ausprobieren ist einer der Gründe, warum man Agenten auf Branches arbeiten lässt und nicht direkt am Hauptstand.
