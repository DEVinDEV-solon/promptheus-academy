# Verifizierer

> Ein Verifizierer beantwortet nur eine Frage: Stimmt das?

Das kann ein Rechenprogramm sein, eine Testsammlung für Code oder ein Modell, das Beweisschritte nachprüft. Im Training liefert er die Belohnung, beim Antworten kann er unter mehreren Entwürfen den richtigen auswählen.

**Prüfen ist oft leichter als Lösen.** Darauf beruht die Idee: Wer gut prüfen kann, kann ein Modell zum guten Lösen erziehen.
