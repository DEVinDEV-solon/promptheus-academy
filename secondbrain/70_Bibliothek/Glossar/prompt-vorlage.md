# Prompt-Vorlage

> Eine Prompt-Vorlage ist ein bewährter Prompt mit Platzhaltern — etwa für Thema, Zielgruppe und Länge.

So muss niemand jedes Mal von vorn formulieren, und die Ergebnisse bleiben vergleichbar. In Programmen werden die Lücken automatisch gefüllt.

Gute Vorlagen sind getestet: Man weiss, wie sie sich bei verschiedenen Eingaben verhalten.
