# Drift

> Drift beschreibt schleichende Veränderung: Die Welt ändert sich, aber das Modell bleibt beim alten Stand — oder das Modell ändert sich, ohne dass es jemand bemerkt.

Ein Betrugserkennungssystem, das vor zwei Jahren trainiert wurde, kennt neue Maschen nicht. Ein Anbieter aktualisiert sein Modell, und Antworten fallen anders aus.

Regelmässige Messung mit denselben Tests macht Drift sichtbar.
