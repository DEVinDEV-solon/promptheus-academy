# Cache (Zwischenspeicher)

> Ein Cache ist ein kleiner, schneller Speicher für Daten, die bald wieder gebraucht werden.

Das Prinzip gibt es überall: im Prozessor, im Browser, beim Sprachmodell. Wer schon einmal geholt wurde, liegt beim zweiten Mal bereit.

Das Schwierige ist die Frage, wann ein Cache veraltet ist. Ein veralteter Cache liefert falsche Antworten — flott.
