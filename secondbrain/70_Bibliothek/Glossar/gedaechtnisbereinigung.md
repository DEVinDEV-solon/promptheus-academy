# Gedächtnisbereinigung

> Gedächtnisbereinigung räumt das Agentengedächtnis auf — Doppeltes, Überholtes, Falsches fliegt raus.

Ohne sie sammeln sich Widersprüche: Ein alter Eintrag sagt, die Besprechung sei montags, ein neuer, sie sei dienstags.

**Für Nutzer heisst es auch:** Man sollte einsehen und löschen können, was ein Agent über einen gespeichert hat.
