# SDK

> Ein SDK nimmt einem die Kleinarbeit ab: Anfragen bauen, Antworten auslesen, Fehler behandeln, Wiederholungen regeln.

Statt jede Anfrage von Hand zusammenzusetzen, ruft man eine Funktion auf. Anbieter liefern SDKs meist für mehrere Sprachen.

Darunter liegt immer dieselbe Schnittstelle — wer das versteht, kann sie notfalls auch ohne SDK benutzen.
