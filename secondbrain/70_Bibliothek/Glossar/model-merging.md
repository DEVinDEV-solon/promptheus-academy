# Model Merging (Modelle verschmelzen)

> Beim Model Merging werden die Gewichte mehrerer feinabgestimmter Modelle gemittelt oder geschickt kombiniert — ganz ohne neues Training.

Ein Modell, das gut Deutsch kann, und eines, das gut programmiert, ergeben so manchmal eines, das beides kann. Das funktioniert nur, wenn beide vom selben Basismodell abstammen.

In der Gemeinschaft offener Modelle ist das ein beliebtes, billiges Experimentierfeld. Warum es so oft klappt, ist noch nicht vollständig verstanden.
