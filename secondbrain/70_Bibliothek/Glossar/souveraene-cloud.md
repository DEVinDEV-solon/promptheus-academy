# Souveräne Cloud

> Eine souveräne Cloud stellt sicher, dass Daten und Betrieb ausschliesslich europäischem — oder nationalem — Recht unterliegen.

Hintergrund: Anbieter aus anderen Ländern können verpflichtet sein, Behörden ihres Heimatlandes Zugriff zu geben, auch auf Daten in Europa.

Für Verwaltung, Gesundheit und Schulen ist das eine zentrale Frage.

Souveränität hat mehrere Ebenen: Wo stehen die Rechner, wer betreibt sie, wessen Recht gilt, und wer liefert Software und Chips? Eine Cloud in Europa mit Technik von anderswo ist nur teilweise souverän. Ganz unabhängig zu werden, ist ein langer Weg.
