# EPR-Korrelation (Verschränkung)

> Verschränkung heißt: Zwei Teilchen bilden einen gemeinsamen Zustand. Gemessen wird an einem — das Ergebnis gehört aber zu beiden.

Einstein, Podolsky und Rosen hielten das 1935 für einen Fehler im Formalismus, weil es ihrer Relativitätstheorie widersprach: Kein Signal ist schneller als das Licht. Die Antwort der Quantenmechaniker: Es wird nichts übertragen, die beiden Orte teilen einen Zustand.

John Bell formulierte 1964 eine messbare Ungleichung, Alain Aspect bestätigte sie 1982. Praktisch wird daraus Quantenkommunikation: Ein Lauschangriff zerstört den Zustand und fällt auf.
