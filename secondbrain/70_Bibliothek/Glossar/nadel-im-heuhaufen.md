# Nadel im Heuhaufen (Needle in a Haystack)

> Beim Heuhaufen-Test versteckt man einen Satz in einem riesigen Text und fragt danach.

Fast alle aktuellen Modelle bestehen diesen Test mit Bravour. **Das sagt aber wenig.** Ein Satz wiederzufinden ist leichter, als viele verstreute Stellen zu verknüpfen. Schwerere Tests zeigen, dass das Verstehen langer Texte deutlich früher nachlässt als das Wiederfinden.
