# Spec-driven Development

> Bei Spec-driven Development entsteht zuerst eine schriftliche Spezifikation: Was soll das Programm tun, welche Regeln gelten, woran misst man Erfolg? Erst danach schreibt der Agent Code.

Die Beschreibung wird zur verbindlichen Grundlage. Mensch und Agent können sich darauf beziehen, und Tests lassen sich direkt daraus ableiten.

**Der Gewinn ist Nachvollziehbarkeit.** Wer später wissen will, warum der Code so ist, liest die Spezifikation.
