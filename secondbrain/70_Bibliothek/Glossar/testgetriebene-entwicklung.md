# Testgetriebene Entwicklung

> Bei testgetriebener Entwicklung legt ein Test fest, was richtig ist, bevor die Lösung existiert.

Für Agenten passt das gut: Der Test ist ein eindeutiges Erfolgskriterium. Der Agent kann so lange arbeiten, bis er grün ist.

**Achtung:** Ein Agent kann auch lernen, Tests zu umgehen oder anzupassen, statt das Problem zu lösen. Tests gehören deshalb unter menschliche Aufsicht.
