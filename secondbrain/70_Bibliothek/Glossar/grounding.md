# Grounding (Verankerung)

> Grounding heisst: Jede Aussage einer Antwort soll sich auf ein vorliegendes Dokument, eine Suche oder eine Datenquelle stützen.

Ein verankertes Modell sagt nicht nur, was es glaubt, sondern woher es das hat. Das macht Antworten prüfbar und senkt die Zahl der Erfindungen.

**Ganz verschwinden sie dadurch nicht.** Ein Modell kann eine Quelle falsch wiedergeben oder eine Quelle angeben, in der das Behauptete nicht steht. Nachsehen bleibt Pflicht.
