# Regression (Statistik)

> Regression heisst: aus Merkmalen einen Zahlenwert schätzen, der beliebig fein ausfallen kann.

Wie teuer wird die Wohnung? Wie warm wird es morgen? Wie lange hält der Akku? Das Modell liefert keine Kategorie, sondern eine Zahl auf einer Skala.

Die einfachste Form ist eine Gerade durch eine Punktwolke. Neuronale Netze können dasselbe mit beliebig verbogenen Kurven. Nicht verwechseln mit dem Regressionstest beim Programmieren — der prüft, ob alte Funktionen nach einer Änderung noch gehen.
