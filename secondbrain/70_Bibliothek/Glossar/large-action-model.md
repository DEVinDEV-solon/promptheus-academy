# Large Action Model (LAM)

> Ein Large Action Model übersetzt einen Wunsch in eine Folge von Aktionen — Klicks, Eingaben, Aufrufe.

Die Idee: Statt zu beschreiben, wie man ein Ticket bucht, bucht das Modell es. Der Begriff wird oft werblich verwendet, und die Grenze zu einem Sprachmodell mit Werkzeugen ist unscharf.

Technisch steckt dahinter meist ein Modell, das auf Bildschirmbedienung und Werkzeugaufrufe nachtrainiert wurde.
