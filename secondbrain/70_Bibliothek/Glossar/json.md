# JSON

> JSON schreibt Daten als Paare aus Name und Wert, verschachtelt in geschweiften und eckigen Klammern.

Menschen können es lesen, Programme können es zuverlässig verarbeiten. Fast jede Schnittstelle im Netz spricht JSON, und Werkzeugaufrufe von Sprachmodellen sind meist JSON-Objekte.

Ein fehlendes Komma macht das Ganze ungültig. Deshalb sind Verfahren wichtig, die Modelle zu gültigem JSON zwingen.
