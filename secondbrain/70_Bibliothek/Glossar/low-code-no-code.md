# Low-Code / No-Code

> Low-Code- und No-Code-Werkzeuge lassen Anwendungen aus fertigen Bausteinen zusammensetzen, per Maus statt per Tastatur.

KI hat das erweitert: Statt Bausteine zu ziehen, beschreibt man in Worten, was man braucht. Die Grenze zu Vibe Coding ist fliessend.

Der Vorteil ist die Nähe zur Fachabteilung: Wer den Ablauf kennt, kann ihn selbst bauen. Der Nachteil zeigt sich später, wenn das Gebaute wächst und niemand mehr überblickt, was wo geschieht. Auch hier hilft Dokumentation.
