# Prompt-Bibliothek

> Eine Prompt-Bibliothek hält fest, was funktioniert hat — damit niemand das Rad zweimal erfindet.

Gute Bibliotheken nennen zu jedem Prompt Zweck, Beispielergebnis und Grenzen. Sie werden gepflegt, wenn sich Modelle ändern, denn ein Prompt, der gestern gut war, kann morgen schwächer sein.

In Teams verhindert eine gemeinsame Sammlung, dass jede Person eigene, ungeprüfte Varianten benutzt. Dann lassen sich Ergebnisse vergleichen und Verbesserungen an einer Stelle einpflegen.
