# Agenten-Anleitungsdatei

> Eine Agenten-Anleitungsdatei ist die Hausordnung für KI: Aufbau des Projekts, Befehle zum Testen, Regeln, Verbote.

Coding-Agenten lesen sie zu Beginn jeder Sitzung. So muss man nicht jedes Mal erklären, wie das Projekt funktioniert.

**Was dort steht, wird befolgt** — deshalb gehört sie unter dieselbe Prüfung wie Code.
