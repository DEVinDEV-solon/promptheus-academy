# Episodisches Gedächtnis

> Das episodische Gedächtnis hält fest, was wann geschah: der erste Schultag, das Gespräch von gestern.

In der Psychologie ist es eine der Hauptformen des Langzeitgedächtnisses. Agenten-Entwickler haben den Begriff übernommen: Ein Agent mit episodischem Gedächtnis erinnert sich an frühere Aufgaben und wie sie ausgingen.

So kann er aus Fehlern lernen — „Beim letzten Mal ist dieser Weg gescheitert" —, ohne dass sein Modell neu trainiert wird.
