# Technische Schuld

> Technische Schuld entsteht, wenn man eine schnelle statt einer sauberen Lösung wählt. Wie bei Geldschulden fallen Zinsen an: Jede spätere Änderung wird mühsamer.

Manchmal ist das eine bewusste Entscheidung. Gefährlich wird es, wenn niemand merkt, dass Schulden gemacht wurden — etwa wenn eine KI viel Code erzeugt, den niemand versteht.
