# Shell-Zugriff

> Mit Shell-Zugriff kann ein Agent Programme starten, Dateien verschieben, Software installieren — fast alles, was am Rechner möglich ist.

Für Programmier-Agenten ist das unverzichtbar. Es ist aber auch der grösste denkbare Aktionsraum.

**Deshalb gelten hier die strengsten Regeln**: abgeschottete Umgebung, Positivliste für Befehle, Freigabe für alles Zerstörerische.
