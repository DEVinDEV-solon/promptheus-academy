# Vibe Coding

> Beim Vibe Coding sagt man der KI, was man will, probiert das Ergebnis aus und beschreibt, was noch nicht passt — den Code selbst schaut man kaum an.

Das ist ideal für schnelle Versuche, kleine Werkzeuge und Prototypen. Menschen ohne Programmierkenntnisse können damit eigene Programme bauen.

**Für ernsthafte Software ist es riskant.** Sicherheitslücken, Datenverlust und unwartbarer Code fallen niemandem auf, solange es „funktioniert". Was andere benutzen, braucht Prüfung.
