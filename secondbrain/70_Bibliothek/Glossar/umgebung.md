# Umgebung (Environment)

> Die Umgebung ist alles, worauf ein Agent einwirkt: ein Dateisystem, ein Browser, ein Spiel, eine Firmensoftware.

Beim bestärkenden Lernen ist sie der Übungsplatz: Der Agent handelt, die Umgebung antwortet mit einer neuen Lage und einer Belohnung.

Für das Training von Agenten werden heute viele künstliche Umgebungen gebaut, die echte Arbeitsplätze nachahmen.
