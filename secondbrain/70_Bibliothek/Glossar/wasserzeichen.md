# Wasserzeichen (im Text)

> Ein Wasserzeichen im Text ist ein Muster, das beim Ziehen der Token gezielt eingewebt wird — unsichtbar beim Lesen, nachweisbar mit dem passenden Schlüssel.

Es funktioniert nur, wo das Modell echte Wahl hat: Die Auswahl wird leise in bevorzugte und benachteiligte Token geteilt, und über viele Wörter hinweg entsteht eine Häufung, die kein Zufall erklärt.

**Wo keine Wahl ist, geht auch kein Wasserzeichen hinein.** In einer IBAN, einer Jahreszahl, einem wörtlichen Zitat gibt es nur eine richtige Fortsetzung. Kurze Texte tragen deshalb kaum etwas, und Umschreiben zerstört das Muster.

Und: Es ist keine Prüfung auf Wahrheit. Ein Wasserzeichen sagt „von dieser Maschine geschrieben", nicht „richtig" oder „falsch".
