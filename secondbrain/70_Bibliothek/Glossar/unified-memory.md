# Unified Memory

> Bei Unified Memory greifen Prozessor und Grafikeinheit auf denselben Speicher zu, statt Daten hin- und herzukopieren.

Für lokale Sprachmodelle ist das ein Vorteil: Das ganze Modell kann im grossen gemeinsamen Speicher liegen, der für beide Rechenwerke erreichbar ist.

Deshalb laufen grosse Modelle auf manchen Laptops und kleinen Rechnern erstaunlich gut.
