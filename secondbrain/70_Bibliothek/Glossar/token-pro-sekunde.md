# Token pro Sekunde

> Token pro Sekunde gibt an, wie viele Token ein Modell nach dem Start der Antwort je Sekunde erzeugt.

Gelesen wird mit etwa fünf bis zehn Token pro Sekunde. Alles darüber fühlt sich beim Lesen flüssig an. Für Agenten, die viel Text erzeugen, ohne dass jemand mitliest, zählt jedes Token pro Sekunde mehr.

Das Tempo hängt an Modellgrösse, Hardware und Auslastung. Lokale Modelle auf dem eigenen Rechner sind oft deutlich langsamer als grosse Anbieter.
