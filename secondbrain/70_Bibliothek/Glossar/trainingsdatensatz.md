# Trainingsdatensatz

> Der Trainingsdatensatz ist alles, was das Modell je zu sehen bekommt, bevor es auf die Welt losgelassen wird.

Bei einem Sprachmodell sind das Billionen Token aus Büchern, Webseiten, Code und Gesprächen. Was dort fehlt, kann das Modell nicht wissen; was dort falsch steht, gibt es mit gleicher Sicherheit wieder.

**Die Qualität der Daten prägt das Modell stärker als fast alles andere.** Deshalb wird heute mehr Mühe auf Auswahl und Säuberung verwendet als auf neue Bauweisen. Und deshalb ist die Frage, wessen Texte da drinstecken, auch eine rechtliche.
