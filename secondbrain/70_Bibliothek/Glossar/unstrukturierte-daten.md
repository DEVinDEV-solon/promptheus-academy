# Unstrukturierte Daten

> Unstrukturierte Daten haben keine vorgegebene Ordnung: eine E-Mail, ein Foto, eine Sprachnachricht.

Der grösste Teil allen Wissens in Organisationen liegt so vor. Lange war es für Programme kaum nutzbar.

**Sprachmodelle haben das verändert.** Sie können solche Daten lesen, zusammenfassen und in Ordnung bringen. Deshalb ist die Erschliessung dieser Datenberge eine der wichtigsten Anwendungen.
