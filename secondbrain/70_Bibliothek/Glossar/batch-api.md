# Batch-API

> Eine Batch-API nimmt einen Stapel von Anfragen entgegen und liefert die Antworten innerhalb von Stunden zurück.

Der Anbieter kann die Arbeit in ruhige Zeiten legen und gibt den Vorteil als Rabatt weiter, oft die Hälfte des Preises.

Für alles, was nicht sofort gebraucht wird — Auswertungen, Übersetzungen, Tests —, ist das die wirtschaftlichere Wahl.
