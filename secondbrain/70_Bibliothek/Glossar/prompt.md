# Prompt

> Der Prompt ist alles, was das Modell vor seiner Antwort zu sehen bekommt: deine Frage, die Regeln, den Zusammenhang.

Das Wort heißt im Englischen „Stichwort" oder „Souffleur" — und das trifft es. Das Modell hat kein Gedächtnis zwischen zwei Gesprächen; was es weiß, steht im Prompt oder es weiß es nicht.

Deshalb ist ein Prompt kein Suchbegriff. Bei einer Suchmaschine sind drei Wörter besser als ein Satz. Hier ist es umgekehrt: Rolle, Aufgabe, Beispiel und Format machen aus einer beliebigen Antwort eine brauchbare.
