# Timeout

> Ein Timeout bricht eine Anfrage ab, wenn sie zu lange dauert, damit das Programm nicht ewig hängt.

Bei Sprachmodellen ist die richtige Frist schwer zu wählen: Eine kurze Antwort braucht Sekunden, ein Denkmodell bei einer schweren Aufgabe Minuten. Zu knapp gewählt, bricht gute Arbeit ab; zu grosszügig, wartet man lange auf eine Störung.
