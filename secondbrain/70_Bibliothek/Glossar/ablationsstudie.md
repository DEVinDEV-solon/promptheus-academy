# Ablationsstudie

> Bei einer Ablationsstudie entfernt man gezielt einen Teil — eine Schicht, eine Datenquelle, einen Prompt-Abschnitt — und misst, was sich ändert.

So findet man heraus, was wirklich zur Leistung beiträgt und was nur Ballast ist. Das Prinzip lässt sich auch im Alltag anwenden: Bringt dieser Absatz im Prompt etwas? Weglassen und testen.
