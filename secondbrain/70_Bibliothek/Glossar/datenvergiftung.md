# Datenvergiftung (Data Poisoning)

> Bei der Datenvergiftung schleust jemand präparierte Beispiele ins Training, damit das Modell später in bestimmten Fällen falsch reagiert.

Untersuchungen zeigten, dass dafür schon wenige hundert Dokumente genügen können — unabhängig davon, wie gross das Modell ist. Eine versteckte Auslöserphrase lässt das Modell dann etwas Bestimmtes tun.

Weil Modelle aus dem offenen Netz lernen, ist das ein ernstes Sicherheitsproblem. Herkunft und Prüfung der Daten werden deshalb wichtiger.
