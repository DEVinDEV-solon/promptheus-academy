# Codeinterpreter

> Mit einem Codeinterpreter rechnet das Modell nicht im Kopf, sondern schreibt ein kleines Programm und liest dessen Ergebnis.

Für Datenauswertung, Diagramme und genaue Rechnungen ist das viel verlässlicher als Kopfrechnen eines Sprachmodells.

Der Code läuft in einer abgeschotteten Umgebung, damit er keinen Schaden anrichten kann.
