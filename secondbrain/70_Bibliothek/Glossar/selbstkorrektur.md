# Selbstkorrektur

> Selbstkorrektur heisst: Der Agent sieht am Ergebnis, dass etwas nicht stimmt, und repariert es.

Am besten funktioniert das mit äusserer Rückmeldung — eine Fehlermeldung, ein fehlgeschlagener Test, ein leeres Suchergebnis. Ohne solche Signale korrigieren Modelle sich oft nur scheinbar.

**Darum sind Tests für Agenten so wertvoll:** Sie geben ein ehrliches Signal, an dem sich Selbstkorrektur festhalten kann.
