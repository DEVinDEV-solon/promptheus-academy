# Beobachtbarkeit (Observability)

> Beobachtbarkeit heisst, dass ein System genug Spuren hinterlässt, um Fehler zu verstehen, ohne es anzuhalten.

Bei KI-Anwendungen gehören dazu: welche Prompts gingen hinein, welche Werkzeuge wurden aufgerufen, was kostete es, wie lange dauerte es. Ohne diese Sicht ist ein Agent eine Blackbox.

**Achtung beim Datenschutz:** Protokolle enthalten oft persönliche Daten aus den Gesprächen.
