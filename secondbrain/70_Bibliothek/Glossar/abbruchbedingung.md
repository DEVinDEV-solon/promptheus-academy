# Abbruchbedingung

> Eine Abbruchbedingung legt fest, wann die Agentenschleife endet: Ziel erreicht, Limit überschritten, kein Fortschritt mehr.

Ohne sie läuft ein Agent womöglich ewig, wiederholt Versuche oder sucht ins Endlose weiter. Mit zu enger Bedingung gibt er zu früh auf.

Eine gute Bedingung enthält beides: ein Erfolgskriterium und eine harte Obergrenze.
