# Neuronales Netz

> Ein neuronales Netz ist eine lange Kette einfacher Rechnungen, deren Zahlen nicht von Hand gesetzt, sondern aus Beispielen gelernt werden.

Vorne gehen Zahlen hinein — Pixel, Token, Messwerte. Hinten kommt eine Antwort heraus. Dazwischen liegen Schichten von Neuronen, die die Eingabe Stück für Stück umformen.

Niemand schreibt hinein, wie eine Katze aussieht. Das Netz bekommt viele Bilder mit der richtigen Antwort und stellt seine Gewichte so lange nach, bis es selbst richtig liegt. **Was es dabei gelernt hat, steht nirgends lesbar drin** — es steckt verteilt in Milliarden Zahlen.
