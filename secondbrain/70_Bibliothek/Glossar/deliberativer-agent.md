# Deliberativer Agent

> Ein deliberativer Agent baut sich ein inneres Bild der Lage, wägt Möglichkeiten ab und wählt dann.

Das ist gründlich, aber langsam. Für Aufgaben mit vielen Fallstricken lohnt es sich.

Der Begriff stammt aus der älteren Agentenforschung, lange vor den Sprachmodellen. Heutige Denkmodelle sind in diesem Sinn deliberativ.
