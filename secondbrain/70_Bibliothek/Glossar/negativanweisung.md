# Negativanweisung

> Eine Negativanweisung verbietet etwas: „Erwähne keine Preise." „Benutze keine Fachwörter."

Das funktioniert schlechter als erwartet. Wer „denk nicht an einen rosa Elefanten" liest, denkt an einen. Ein Modell, das das Verbotene im Prompt liest, hat es danach im Kontext.

**Besser wirkt, das Gewünschte positiv zu beschreiben**: „Erkläre in Alltagssprache" statt „Keine Fachwörter". Bei Bildgeneratoren gibt es ein eigenes Feld für Negativprompts, das technisch anders funktioniert.
