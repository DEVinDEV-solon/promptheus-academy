# MCP-Client

> Ein MCP-Client verbindet sich mit einem oder mehreren MCP-Servern und reicht deren Werkzeuge an das Modell weiter.

Chat-Programme, Entwicklungsumgebungen und Agenten können solche Clients sein. Weil die Norm offen ist, funktioniert derselbe Server mit vielen Clients.

Der Client entscheidet auch, was der Mensch sieht und freigeben muss. Ein guter Client zeigt an, welcher Server welches Werkzeug aufruft, und fragt nach, bevor etwas Folgenreiches geschieht.
