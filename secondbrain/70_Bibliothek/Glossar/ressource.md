# Ressource (MCP)

> Eine Ressource ist bei MCP ein Inhalt, den der Server anbietet: eine Datei, ein Datensatz, eine Seite.

Anders als ein Werkzeug tut sie nichts, sie wird nur gelesen. Das Programm kann sie dem Modell als Hintergrund geben.

Neben Werkzeugen und Ressourcen kennt MCP noch vorbereitete Prompts, die ein Server mitbringen kann.
