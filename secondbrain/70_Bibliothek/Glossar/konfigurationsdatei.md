# Konfigurationsdatei

> Eine Konfigurationsdatei hält fest, wie sich ein Programm verhalten soll — getrennt vom eigentlichen Code.

So lassen sich Einstellungen ändern, ohne den Code anzufassen. **Geheimnisse gehören nicht hinein**, wenn die Datei geteilt oder hochgeladen wird; dafür gibt es Umgebungsvariablen und Tresore.

Für Agenten sind Konfigurationsdateien ein typischer Ort, an dem sie Verhalten ändern können — etwa Berechtigungen oder Werkzeuge. Änderungen an solchen Dateien verdienen deshalb einen besonders genauen Blick.
