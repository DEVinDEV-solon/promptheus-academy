# Inferenzserver

> Ein Inferenzserver hält ein Modell im Speicher, nimmt Anfragen entgegen, bündelt sie geschickt und liefert die Antworten aus.

Er kümmert sich um KV-Cache, Batching, Speicheraufteilung und Streaming. Gute Inferenzserver holen aus derselben Hardware ein Vielfaches an Leistung heraus.

Wer ein Modell selbst betreibt, wählt zuerst so einen Server.
