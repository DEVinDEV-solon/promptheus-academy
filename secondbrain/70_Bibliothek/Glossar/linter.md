# Linter

> Ein Linter liest Code und meldet Auffälligkeiten: unbenutzte Variablen, verdächtige Konstruktionen, Abweichungen vom vereinbarten Stil.

Für Agenten ist er ein billiger, schneller Prüfer, der vor teureren Tests viele Fehler abfängt.

Viele Linter können gefundene Kleinigkeiten auch gleich selbst beheben. Ein einheitlicher Stil erleichtert das Lesen von Code, der von verschiedenen Menschen und Agenten stammt. Wichtig bleibt: Ein Linter prüft die Form, nicht, ob das Programm das Richtige tut.
