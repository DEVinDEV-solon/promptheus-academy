# Ausgabeformat

> Das Ausgabeformat legt fest, in welcher Form das Ergebnis kommt: drei Stichpunkte, eine Tabelle, ein JSON-Objekt, ein Absatz.

Wer es nicht angibt, bekommt die Form, die das Modell für üblich hält — oft länger und verschachtelter als gewünscht.

Für Programme, die mit der Antwort weiterarbeiten, ist ein festes Format Pflicht. Dafür gibt es strukturierte Ausgaben, die das Modell an ein Schema binden.
