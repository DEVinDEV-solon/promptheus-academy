# Agent Card

> Eine Agent Card beschreibt einen Agenten in maschinenlesbarer Form: Name, Fähigkeiten, Adresse, nötige Anmeldung.

Andere Agenten lesen sie, um zu entscheiden, ob dieser Agent für eine Aufgabe in Frage kommt. Sie ist das Gegenstück zur Werkzeugbeschreibung, nur für ganze Agenten.

Wie bei einer echten Visitenkarte zählt, was darauf steht, und ob man der Quelle traut. Eine Agent Card kann sich als etwas ausgeben, das der Agent dahinter gar nicht ist. Deshalb werden Karten zunehmend signiert, damit ihre Herkunft prüfbar ist.
