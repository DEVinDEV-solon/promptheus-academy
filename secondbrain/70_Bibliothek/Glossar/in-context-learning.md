# In-Context Learning

> In-Context Learning heisst: Das Modell passt sein Verhalten an Beispiele und Erklärungen im Prompt an — nur für dieses eine Gespräch.

Gibt man ihm drei Beispiele einer erfundenen Sprache, übersetzt es den vierten Satz. Es hat nichts dauerhaft gelernt; mit dem nächsten Gespräch ist alles vergessen.

**Das ist die Fähigkeit, die Prompting überhaupt möglich macht.** Ohne sie müsste jedes Modell für jede neue Aufgabe neu trainiert werden.
