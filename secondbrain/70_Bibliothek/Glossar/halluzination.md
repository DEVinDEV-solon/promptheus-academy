# Halluzination

> Eine Halluzination ist eine erfundene Angabe, die das Modell im selben sicheren Ton vorträgt wie eine richtige.

Das Wort ist eine Beschönigung. Ein Mensch, der halluziniert, ist krank; ein Modell, das halluziniert, arbeitet völlig normal. Es sagt vorher, wie ein plausibler Text weitergeht — und ein erfundenes Urteil mit Aktenzeichen ist ein sehr plausibler Text.

**Deshalb gibt es kein Warnzeichen.** Das Modell weiß nicht, dass es gerade erfindet. Es gibt keine innere Stelle, an der zwischen „gewusst" und „geraten" unterschieden würde. Wer Belege braucht, muss sie selbst prüfen.
