# Webhook

> Ein Webhook ist ein Rückruf: Statt ständig nachzufragen „ist etwas neu?", meldet sich der Dienst von selbst unter einer vereinbarten Adresse.

Ein Bezahldienst meldet „Zahlung eingegangen", ein Formular meldet „neue Anmeldung". Agenten können so auf Ereignisse reagieren.

**Weil jeder an diese Adresse schreiben kann**, muss der Empfänger prüfen, ob die Nachricht wirklich vom erwarteten Dienst stammt.
