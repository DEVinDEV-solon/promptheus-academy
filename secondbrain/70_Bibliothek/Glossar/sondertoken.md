# Sondertoken (Special Token)

> Sondertoken sind reservierte Einträge im Vokabular, die Anfang, Ende, Sprecherwechsel oder Werkzeugaufrufe markieren.

Sie tauchen in der Antwort nicht als Text auf, steuern aber das Verhalten. Ein Sondertoken sagt etwa: Hier beginnt eine Nachricht des Systems, hier spricht der Nutzer, hier ruft das Modell ein Werkzeug auf.

Weil sie so mächtig sind, wird bei der Eingabe darauf geachtet, dass niemand sie als gewöhnlichen Text einschmuggeln kann.
