# Hochgeschwindigkeitsnetz

> Ein Hochgeschwindigkeitsnetz verbindet tausende Chips so eng, dass sie gemeinsam an einem Modell rechnen können.

Dafür werden spezielle Netzwerktechniken und zunehmend Lichtleiter direkt an den Chips eingesetzt. Ein grosser Teil der Kosten eines KI-Clusters steckt im Netz.

Fällt in einem solchen Netz eine Leitung aus, kann ein ganzes Training stocken. Deshalb werden Netze mit Umwegen gebaut, auf die der Verkehr ausweichen kann. Ihre Planung ist eine eigene Fachrichtung geworden.
