# Paketmanager

> Ein Paketmanager holt fremde Bibliotheken aus einem Verzeichnis und sorgt dafür, dass die richtigen Fassungen zusammenpassen.

Jede Programmiersprache hat ihren eigenen. Agenten nutzen ihn, um fehlende Bausteine nachzuinstallieren — **was immer eine Prüfung wert ist**, denn jedes Paket ist fremder Code.

Ein Paketmanager führt auch Buch: In einer Datei steht, welche Pakete in welcher Fassung benutzt werden. Dadurch kann jemand anderes das Projekt auf seinem Rechner genauso einrichten. Diese Datei gehört ins Repository, die heruntergeladenen Pakete selbst meist nicht.
