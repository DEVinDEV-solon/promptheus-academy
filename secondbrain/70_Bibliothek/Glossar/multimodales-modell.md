# Multimodales Modell

> Ein multimodales Modell kann ein Foto ansehen, eine Frage dazu lesen und eine Antwort sprechen — in einem einzigen Modell.

Technisch werden dafür Bilder und Töne in dieselbe Art von Token übersetzt wie Text. Für das Modell ist ein Bildausschnitt dann ein Stück Eingabe wie ein Wort.

Das eröffnet Aufgaben, die vorher getrennte Programme brauchten: ein Diagramm erklären, einen Bildschirm bedienen, ein Gespräch in Echtzeit führen. **Die Schwächen wandern mit**: Ein Modell kann auch in einem Bild etwas sehen, das nicht da ist.
