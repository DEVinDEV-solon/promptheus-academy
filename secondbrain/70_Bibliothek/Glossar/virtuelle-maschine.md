# Virtuelle Maschine

> Eine virtuelle Maschine hat ein eigenes Betriebssystem, eigenen Speicher und eigene Festplatte — alles nur nachgebildet.

Was darin geschieht, bleibt darin. Für Agenten mit Computersteuerung ist sie die sicherste Spielwiese.

Sie ist schwerer als ein Container, aber stärker abgeschottet.

Für Agenten hat sie einen weiteren Vorteil: Man kann einen Zustand speichern und nach einem missglückten Versuch dorthin zurückkehren. Ein Agent, der sich verirrt, richtet so keinen bleibenden Schaden an.
