# Inverses Problem

> Beim inversen Problem kennt man nur das Ergebnis einer Messung und will auf das Objekt zurückschließen: aus dem CT-Bild auf das Gewebe.

Jede Messung ist verrauscht. Für digitale neuronale Netze gibt es eine bewiesene untere Schranke — die Rekonstruktion wird ab einem Punkt nicht genauer. Für einen Analogrechner gibt es diese Schranke nicht.

Deshalb ist das kein Mathematiker-Sonderfall, sondern eine Frage der Medizintechnik: Heute reicht die Genauigkeit, morgen vielleicht nicht.
