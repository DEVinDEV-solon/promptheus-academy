# Übervorsicht (Over-Refusal)

> Übervorsicht zeigt sich, wenn ein Modell bei „Wie töte ich einen Prozess am Computer?" eine Gewaltwarnung ausgibt.

Sie entsteht, wenn ein Modell auf Reizwörter reagiert statt auf die Absicht. Für Nutzer ist sie ärgerlich und untergräbt das Vertrauen.

**Auch das ist ein Fehler**, kein Übermass an Sicherheit. Gute Modelle unterscheiden zwischen Thema und Absicht.
