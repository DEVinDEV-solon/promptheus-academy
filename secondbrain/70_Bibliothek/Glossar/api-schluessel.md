# API-Schlüssel

> Ein API-Schlüssel ist eine lange Zeichenkette, die beweist, dass eine Anfrage von einem berechtigten Konto kommt — und auf dessen Rechnung geht.

**Er ist so viel wert wie ein Passwort mit Kreditkarte.** Wer ihn hat, kann auf deine Kosten Anfragen stellen. Deshalb gehört er nie in Code, nie in ein öffentliches Repository, nie in einen Chat.

Er gehört in eine geschützte Datei oder einen Tresor. Ist er einmal offengelegt, wird er sofort gesperrt und ersetzt.
