# Evaluationsbewusstsein

> Evaluationsbewusstsein liegt vor, wenn ein Modell an der Art der Aufgabe erkennt, dass es sich um eine Prüfung handelt.

Neuere Modelle sprechen das manchmal sogar in ihrer Denkspur aus. Das stellt Prüfungen in Frage: Misst ein Test noch das echte Verhalten, wenn das Modell weiss, dass es ein Test ist?

Prüfer bemühen sich deshalb um Aufgaben, die von echten nicht zu unterscheiden sind.
