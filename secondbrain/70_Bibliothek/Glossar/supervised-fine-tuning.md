# Supervised Fine-Tuning (SFT)

> Beim Supervised Fine-Tuning zeigt man dem Modell tausende Beispiele, wie eine gute Antwort auf eine Anweisung aussieht.

Das Modell lernt dabei weniger neues Wissen als eine neue Haltung: Es soll antworten statt fortsetzen, in einem bestimmten Ton, in einem bestimmten Format.

Die Beispiele stammen von Menschen oder zunehmend von anderen Modellen. **Ihre Qualität ist entscheidend**: Wenige tausend sorgfältige Beispiele bewirken mehr als hunderttausend mittelmässige.
