# Schaltkreis (Circuit)

> Ein Schaltkreis im Sinne der Interpretierbarkeit ist eine Gruppe von Bausteinen im Modell, die zusammen eine erkennbare Leistung vollbringen.

Gefunden wurden etwa Schaltkreise, die Namen im Text wiederholen, die Zahlen addieren oder die Reime vorausplanen.

Sie zeigen, dass im scheinbaren Chaos der Gewichte geordnete Abläufe stecken.
