# ReAct-Muster

> Beim ReAct-Muster schreibt das Modell abwechselnd einen Gedanken („Ich muss das Wetter nachschlagen"), eine Aktion (Werkzeugaufruf) und liest die Beobachtung.

Der Name verbindet Reasoning und Acting. Die Idee von 2022: Gedanken helfen beim Handeln, und Handlungsergebnisse helfen beim Denken.

Heutige Agenten folgen diesem Grundgedanken, auch wenn sie das Muster nicht mehr so ausdrücklich ausschreiben.
