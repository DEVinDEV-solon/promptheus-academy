# Rechenzentrum

> Ein Gebäude voller Regale mit Rechnern, Kühlung und eigener Stromversorgung. Wenn jemand sagt „in der Cloud", meint er ein Rechenzentrum, das jemand anderem gehört.

„Die Cloud" ist der irreführendste Begriff der Branche. Nichts daran schwebt: Es ist eine Halle an einem bestimmten Ort, mit einer Adresse, unter der Rechtsordnung eines bestimmten Landes.

Das ist keine Kleinigkeit, sondern die Frage, wer auf die Daten zugreifen darf. Und es ist eine Umweltfrage: Ein grosses Rechenzentrum verbraucht so viel Strom wie eine Kleinstadt, dazu Wasser für die Kühlung.

Deshalb ist es ein Unterschied, ob ein Modell auf einer [[npu]] im eigenen Gerät läuft oder in einer Halle auf einem anderen Kontinent.
