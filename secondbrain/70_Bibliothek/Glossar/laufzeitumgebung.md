# Laufzeitumgebung (Runtime)

> Eine Laufzeitumgebung stellt alles bereit, was ein Programm zum Laufen braucht: Speicher, Rechenwerke, Bibliotheken.

Für KI-Modelle übersetzt sie die Rechnungen auf die vorhandene Hardware — Grafikkarte, Prozessor oder KI-Chip. Je nach Laufzeit läuft dasselbe Modell unterschiedlich flott.

Wer ein Modell lokal betreibt, merkt das deutlich: Dieselbe Datei kann in einer Laufzeit doppelt so viele Token pro Sekunde liefern wie in einer anderen, je nachdem, wie gut sie die vorhandenen Rechenwerke nutzt.
