# Matrix

> Eine Matrix ist ein Zahlenfeld mit Zeilen und Spalten. Ein Vektor, mit ihr multipliziert, kommt als neuer Vektor wieder heraus.

Jede Schicht eines Netzes ist im Kern eine solche Multiplikation. Fast die gesamte Rechenzeit einer KI geht dafür drauf, Matrizen mit Matrizen zu multiplizieren.

**Deshalb sind Grafikprozessoren so wichtig.** Sie können tausende dieser einfachen Multiplikationen gleichzeitig ausführen. Chips, die eigens für KI gebaut werden, sind im Grunde sehr schnelle Matrixmultiplizierer.
