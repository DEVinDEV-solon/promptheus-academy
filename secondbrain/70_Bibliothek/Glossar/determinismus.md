# Determinismus

> Ein deterministisches System liefert bei gleicher Eingabe immer das Gleiche. Sprachmodelle tun das meist nicht.

Der Hauptgrund ist das Ziehen aus der Wahrscheinlichkeitsverteilung. Aber selbst bei Temperatur null schwanken Antworten oft leicht, weil Rechenreihenfolgen auf den Chips variieren.

Für Tests und Nachvollziehbarkeit ist das ein Problem. Man prüft deshalb nicht eine Antwort, sondern viele.
