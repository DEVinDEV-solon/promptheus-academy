# Eval (Evaluation)

> Ein Eval ist eine Sammlung von Prüffällen mit klarer Bewertung, die man jederzeit erneut laufen lassen kann.

Ohne Evals ist jede Verbesserung ein Gefühl. Mit ihnen sieht man: Der neue Prompt löst 87 statt 81 von 100 Fällen — oder er hat drei alte Fälle kaputt gemacht.

**Die besten Evals stammen aus dem echten Einsatz**: Fälle, an denen das System tatsächlich gescheitert ist. Allgemeine Benchmarks sagen wenig darüber, ob ein Modell für deine Aufgabe taugt.
