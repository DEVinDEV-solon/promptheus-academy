# Browser-Agent

> Ein Browser-Agent öffnet Seiten, klickt, füllt Formulare aus und liest Ergebnisse — im Auftrag eines Menschen.

So kann er Preise vergleichen, Termine buchen oder Recherchen erledigen.

**Webseiten sind fremdes Gelände.** Eine präparierte Seite kann versteckte Anweisungen enthalten. Ein Browser-Agent sollte deshalb nichts Folgenreiches tun, ohne zu fragen.
