# Modell-Routing

> Beim Modell-Routing entscheidet ein vorgeschalteter Schritt, ob eine Anfrage ein kleines, günstiges oder ein grosses, teures Modell braucht.

Eine Begrüssung braucht kein Spitzenmodell, ein kniffliger Vertrag schon. Ein Router kann die Kosten deutlich senken, ohne dass die Qualität leidet.

Die Kunst ist, Schwierigkeit vorher richtig einzuschätzen. Ein falsch zugeordneter Fall bekommt eine schwache Antwort.
