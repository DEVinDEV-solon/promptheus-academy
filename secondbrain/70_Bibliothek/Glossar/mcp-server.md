# MCP-Server

> Ein MCP-Server macht einen Dienst für KI-Programme benutzbar: einen Kalender, eine Datenbank, ein Dateisystem.

Er beschreibt seine Werkzeuge so, dass das Modell versteht, was sie tun, und führt sie aus, wenn das Modell sie aufruft.

**Ein MCP-Server ist Code mit Zugriff** — oft auf sensible Daten. Fremde Server sollte man prüfen wie jede andere Software, bevor man sie einbindet.
