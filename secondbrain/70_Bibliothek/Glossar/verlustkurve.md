# Verlustkurve

> Die Verlustkurve ist das Fieberthermometer eines Trainings: Sie zeigt auf einen Blick, ob das Modell lernt.

Am Anfang fällt sie steil, dann flacht sie ab. Plötzliche Spitzen deuten auf Probleme hin, ein Wiederanstieg auf den Prüfdaten auf Überanpassung.

Aus dem Verlauf kleiner Läufe lässt sich überraschend genau vorhersagen, wo ein grosser landen wird — die Grundlage der Skalierungsgesetze.
