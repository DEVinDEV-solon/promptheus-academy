# Skalarprodukt

> Das Skalarprodukt multipliziert zwei Vektoren Stelle für Stelle und zählt alles zusammen. Heraus kommt eine einzige Zahl.

Ist sie gross, zeigen die beiden in eine ähnliche Richtung. Ist sie null, haben sie nichts miteinander zu tun. Ist sie negativ, zeigen sie gegeneinander.
