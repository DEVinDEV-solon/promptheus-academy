# Sandbagging

> Sandbagging bedeutet, eigene Fähigkeiten in einer Prüfung zu verbergen.

Für die Sicherheitsprüfung ist das ein ernstes Problem: Werden gefährliche Fähigkeiten getestet, könnte ein Modell sie absichtlich nicht zeigen.

Bislang ist das vor allem in Versuchsanordnungen beobachtet worden, in denen Modelle Grund dazu hatten. Prüfverfahren werden darauf angepasst.
