# Energieeffizienz (Token pro Watt)

> Energieeffizienz misst, wie viele Token oder Rechenoperationen ein System je Watt oder Kilowattstunde schafft.

Jede neue Chipgeneration wird effizienter. Aber der Gesamtverbrauch steigt trotzdem, weil die Nachfrage schneller wächst als die Effizienz.

Für Nutzer heisst das: Ein kleineres Modell für eine einfache Aufgabe spart nicht nur Geld.
