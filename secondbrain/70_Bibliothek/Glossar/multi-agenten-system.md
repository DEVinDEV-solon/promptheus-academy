# Multi-Agenten-System

> Ein Multi-Agenten-System verteilt Arbeit auf mehrere spezialisierte Agenten, die sich abstimmen.

Ein Agent recherchiert, einer schreibt, einer prüft. Für breite Aufgaben mit vielen unabhängigen Teilen kann das deutlich bessere Ergebnisse bringen.

**Es kostet aber ein Vielfaches an Token**, und die Abstimmung ist fehleranfällig: Missverständnisse zwischen Agenten sind so real wie zwischen Menschen. Für viele Aufgaben ist ein einzelner gut ausgestatteter Agent die bessere Wahl.
