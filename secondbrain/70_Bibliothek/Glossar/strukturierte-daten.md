# Strukturierte Daten

> Strukturierte Daten sind geordnet: Name in diese Spalte, Datum in jene, Betrag in die dritte.

Programme können sie zuverlässig auswerten, sortieren und rechnen. Datenbanken und Tabellenkalkulationen arbeiten so.

Sprachmodelle sind gut darin, aus unstrukturiertem Text strukturierte Daten zu machen — etwa aus einer E-Mail die Felder einer Bestellung.
