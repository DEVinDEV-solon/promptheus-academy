# Personalisierung

> Personalisierung heisst, dass ein System Vorlieben, Vorwissen und Ziele einer Person berücksichtigt.

Das macht Antworten passender: Eine Fachfrau bekommt andere Erklärungen als ein Neuling. Dafür muss das System aber etwas über die Person wissen und speichern.

**Je persönlicher, desto heikler.** Gute Personalisierung ist sparsam, durchschaubar und abschaltbar.
