# Reaktiver Agent

> Ein reaktiver Agent folgt festen Reiz-Antwort-Regeln: Sieht er dies, tut er das.

Er reagiert ohne Verzögerung und ist berechenbar, aber begrenzt. Ein Saugroboter, der bei einer Wand umdreht, arbeitet so.

Viele praktische Systeme kombinieren eine reaktive Schicht für Routine mit einer planenden für schwierige Fälle.
