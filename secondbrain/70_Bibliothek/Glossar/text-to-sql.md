# Text-to-SQL

> Text-to-SQL übersetzt „Wie viel haben wir im März in Bayern verkauft?" in die Abfragesprache einer Datenbank.

Damit können auch Menschen ohne Programmierkenntnisse Daten auswerten. Das Modell muss dafür den Aufbau der Datenbank kennen.

**Prüfen bleibt nötig:** Eine falsch verknüpfte Tabelle liefert eine plausible, aber falsche Zahl. Und das Modell sollte nur lesen dürfen, nie ändern oder löschen.
