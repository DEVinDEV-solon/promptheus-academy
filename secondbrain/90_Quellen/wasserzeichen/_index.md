# Quellen aus `21_Wasserzeichen`

Wie ein Sprachmodell wirklich rechnet: Tokens, Logits, Sampling. Und Herkunftsnachweis.

Geerntet mit `setup/ernte.php`. Jede Notiz trägt im Frontmatter `herkunft:` mit Vault, Pfad, Datum und Prüfsumme. Wer eine Notiz hier von Hand nachbearbeitet, setzt `handverlesen: true` — dann meldet die Ernte eine Änderung an der Quelle, ersetzt die Notiz aber nicht.

Stand: **10 Notizen**.
