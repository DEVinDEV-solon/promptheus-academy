# Entropie

> Entropie misst, wie offen die nächste Entscheidung ist. Steht praktisch fest, welches Token kommt, ist sie niedrig; sind viele gleich plausibel, ist sie hoch.

Nach „Die Hauptstadt von Frankreich ist" ist die Entropie fast null — es gibt nur eine sinnvolle Fortsetzung. Nach „Er öffnete die Tür und" ist sie hoch.

Für die Kennzeichnung von KI-Text ist Entropie das Budget: nur wo Wahl besteht, kann man etwas hineinschreiben, ohne den Sinn zu ändern.
