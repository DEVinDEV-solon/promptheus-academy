# MCP (Model Context Protocol)

> MCP ist eine offene Vereinbarung, wie ein Modell Werkzeuge und Datenquellen anspricht — unabhängig davon, wer das Modell gebaut hat.

Vorher musste jeder Anbieter jedes Werkzeug einzeln anbinden: bei fünf Modellen und zehn Werkzeugen fünfzig Verbindungen. Mit einer gemeinsamen Norm sind es fünfzehn.

Das ist dieselbe Idee wie beim USB-Stecker, und derselbe Nutzen: Wer ein Werkzeug einmal baut, kann es überall anstecken.
