# Sensor

> Ein Sensor misst etwas Physikalisches — Licht, Wärme, Abstand, Lage, Druck — und gibt es als Zahl weiter.

Kamera, Mikrofon, Thermometer, Bewegungsmelder: alles Sensoren. Ohne sie wüsste ein Roboter nichts von der Welt.

Jeder Sensor hat Grenzen, und sie zu kennen ist die halbe Robotik. Eine Kamera sieht im Dunkeln nichts, ein Abstandssensor wird von Glas getäuscht. Deshalb nehmen ernsthafte Systeme mehrere und vergleichen — was einer allein meldet, ist eine Vermutung.
