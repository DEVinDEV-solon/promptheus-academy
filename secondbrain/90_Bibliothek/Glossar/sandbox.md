# Sandkasten

> Ein Sandkasten (*Sandbox*) ist eine Umgebung, in der Code läuft, ohne an den Rest des Rechners heranzukommen.

Das Bild stimmt: Ein Kind darf im Sandkasten alles umgraben, und der Garten bleibt heil.

Für [[agent|Agenten]] ist das die wichtigste Sicherung überhaupt. Ein Modell, das Befehle ausführen darf, wird irgendwann einen falschen ausführen — nicht aus Bosheit, sondern weil es geraten hat. Die Frage ist nur, was dann passiert.
