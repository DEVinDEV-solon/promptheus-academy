# Automatisierung

> Automatisierung heisst: Ein Ablauf wird so genau festgelegt, dass eine Maschine ihn ohne Zutun wiederholen kann.

Das ist älter als jede KI — eine Waschmaschine ist automatisiert. Neu ist, dass jetzt auch Schritte automatisierbar werden, die **Urteil** verlangen: eine E-Mail einsortieren, eine Beschwerde einschätzen, einen Text zusammenfassen.

**Die alte Regel gilt weiter:** Automatisierung vervielfacht, was da ist. Ein guter Ablauf wird schneller gut, ein schlechter schneller schlecht — nur merkt es niemand mehr, weil niemand mehr hinsieht.

Deshalb gehört zu jeder Automatisierung die Frage, wer das Ergebnis prüft und wie man sie anhält.
