# API (Schnittstelle)

> **A**pplication **P**rogramming **I**nterface: eine Steckdose für Programme. Sie legt fest, was man fragen darf und in welcher Form die Antwort kommt.

Der Sinn ist die Verlässlichkeit. Weil die Form vereinbart ist, kann sich innen alles ändern, ohne dass draussen etwas kaputtgeht.

Fast jede KI, die man benutzt, erreicht man über eine API — auch dann, wenn man nur ein Chatfenster sieht. Und der Unterschied zu [[rpa]] ist genau der: Eine API ist eine gemeinte Tür, RPA ist ein Klettern durchs Fenster.
