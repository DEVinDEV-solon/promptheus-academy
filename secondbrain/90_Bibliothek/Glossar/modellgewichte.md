# Modellgewichte

> Die Gewichte sind das Modell. Alles, was es gelernt hat, steht in diesen Zahlen — es gibt keine Regeln, keine Texte, keine Datenbank daneben.

Ein Modell mit „7B" hat sieben Milliarden solcher Zahlen. Man kann sie ansehen, kopieren und weitergeben — aber niemand kann darin nachschlagen. Es steht nirgends „Paris ist die Hauptstadt von Frankreich"; das Wissen ist über Millionen Zahlen verteilt.

Genau hier liegt der Unterschied zwischen [[open-source]] und [[open-weights]]: Wer die Gewichte herausgibt, gibt das Können heraus — nicht das Rezept.
