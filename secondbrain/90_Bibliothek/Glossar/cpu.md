# CPU (Hauptprozessor)

> **C**entral **P**rocessing **U**nit: der Hauptprozessor. Er führt Befehle der Reihe nach aus und wechselt blitzschnell zwischen Aufgaben.

Eine CPU hat wenige, dafür sehr kluge Kerne — heute meist acht bis dreissig. Jeder kann jede Aufgabe, springt zwischen Programmen und trifft Entscheidungen.

Für ein Sprachmodell ist das die falsche Bauart. Ein Modell rechnet nicht nacheinander, sondern **millionenfach dasselbe gleichzeitig** — dafür braucht es eine [[gpu]].

Ein Bild: Die CPU ist ein sehr guter Koch, der jedes Gericht kann. Die GPU sind tausend Küchenhilfen, die alle nur Zwiebeln schneiden — aber alle auf einmal.
