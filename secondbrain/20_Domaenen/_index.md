# Fachkurse

Zehn Wahlkurse für einzelne Anwendungsbereiche. Laufen neben den Stufen.

Jeder Fachkurs hat neun Lektionen für Erwachsene im Berufsalltag und setzt
Stufe 3 (BUILDER) voraus. Alle folgen demselben Faden: Welche Entscheidung
wird getroffen, was rechnet eine Regel, was formuliert ein Modell — und was
entscheidet ein Mensch? Lektion 9 ist jeweils ein eigener Ablauf aus dem
eigenen Arbeitsumfeld.

| Kurs | Schwerpunkt |
|---|---|
| Handel | Bestand, Preise, Bestellvorschläge |
| Dienstleistung | Termine, Kundenkommunikation, Angebote |
| Bürobetrieb | Posteingang, Ablage, E-Mail-Automation |
| Verkauf | Interessenten, Prognosen, Angebote |
| Beratung | Recherche, Datenanalyse, Berichte |
| Jura | Rechtsrecherche, Verträge, DSGVO, AI Act |
| Sicherheit & Secrets | Secrets, Rechte, Täuschung, Audit-Trail |
| Buchhaltung | Belege, Kontierung, E-Rechnung, GoBD |
| Personalverwaltung | Anzeigen, Auswahl und ihre Grenzen, Zeugnisse |
| Bürokratie & Verwaltung | Anträge, Fristen, Bescheide, Ermessen |
